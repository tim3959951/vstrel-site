Vstrel Uploader

An internal publishing tool operated by VSTREL

  • Privacy Policy
  • Terms of Use

Vstrel Uploader is the tool VSTREL uses to publish its own short videos — the Traditional Chinese AI-explainer series Vstrel — to VSTREL's own accounts on a fixed schedule:

  • YouTube: @VSTREL-AI
  • Instagram: @vstrel.ai
  • Facebook Page: Vstrel

Who uses it

Only VSTREL. The tool runs on a computer owned by VSTREL and is not offered to the public: there is no sign-up, there are no other users, and no third party has access. The only Google account that authorizes it is the account that manages VSTREL's own YouTube channel.

How it uses YouTube API Services

Vstrel Uploader uses YouTube API Services (YouTube Data API v3). After the channel owner signs in with Google (OAuth 2.0), the tool:

  • Uploads our videos (videos.insert) with the title, description and publish time we prepare — published right away, or uploaded as private with a scheduled publish time.
  • Confirms the connected channel (channels.list, mine=true), so videos can only go to VSTREL's channel.
  • Reads details of our own videos (videos.list) — title, description and category — so the same text can be reused when we post the video on our other accounts.

It does not read, collect or store anything about viewers, subscribers, commenters or other channels, and it does not display YouTube content to anyone.

誰會使用

只有 VSTREL。這個工具在 VSTREL 自己的電腦上執行，不對外開放：沒有註冊、沒有其他使用者，也不提供第三方存取。唯一授權它的 Google 帳號，就是管理 VSTREL 自家 YouTube 頻道的帳號。

如何使用 YouTube API 服務

Vstrel Uploader 使用 YouTube API 服務（YouTube Data API v3）。頻道擁有者以 Google 帳號登入授權（OAuth 2.0）後，工具會：

  • 上傳我們的影片（videos.insert），附上我們準備好的標題、說明與發布時間，可以立即發布，或先設為私人並排程公開。
  • 確認連結的頻道（channels.list、mine=true），確保影片只會上傳到 VSTREL 的頻道。
  • 讀取我們自己影片的資料（videos.list）：標題、說明與分類，方便同一支影片發到我們其他帳號時沿用相同文字。

本工具不讀取、不蒐集、也不儲存任何觀眾、訂閱者、留言者或其他頻道的資料，也不會向任何人顯示 YouTube 內容。

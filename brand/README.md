# VSTREL brand assets

Mark: interlocking double-V monogram, drawn as one filled path (evenodd).
Brand colour: vertical gradient #6DCBDD (top) -> #31C3E7 (bottom), sampled from the original mark. On white: #1B7C93 -> #0E9CBE.
Dark ground: #050b18

| File | Use |
|---|---|
| `vstrel-mark.svg` | Dark backgrounds (site, slides, dark UI) |
| `vstrel-mark-light.svg` | White / light backgrounds (cards, letterhead, invoices) |
| `vstrel-mark-mono.svg` | Single colour — inherits `currentColor` (stamps, one-colour print, watermarks) |

| `*-1024.png` | Raster fallback where SVG is not accepted |

Clear space: at least 25% of the mark's height on every side.
Do not add glow, drop shadows, outlines, or rotate the mark.

## Social

| File | Where |
|---|---|
| `social/avatar-dark-1024.png` | LinkedIn / IG / FB / YouTube profile picture |
| `social/avatar-white-1024.png` | Same, for platforms or docs on a light ground |
